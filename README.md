# 高校邦播放助手

高校邦 HTML5 视频的本地播放偏好扩展，适用于支持 Manifest V3 的 Chrome、Edge 及兼容浏览器。

## 功能

- 后台播放：阻止窗口失焦或标签页切换时，网页脚本对正在播放的视频调用 `pause()`。
- 倍速锁定：保持所选速度，默认 1.0 倍，不被页面改为 0.8 倍。
- 工具栏弹窗：启用开关、后台播放开关、倍速锁定开关及 0.5–2.0 倍速选项。
- 自动适配动态插入的 `<video>`，在匹配域名的 iframe 内独立生效。
- 仅在本地保存设置，没有账号读取、遥测、远程代码或外部请求。

## 安装

1. 下载并解压发行包，或使用此项目文件夹，确保根目录包含 `manifest.json`。
2. 在 Edge 打开 `edge://extensions`，或在 Chrome 打开 `chrome://extensions`。
3. 自行打开“开发人员模式”，选择“加载解压缩的扩展”，选中项目根目录。
4. 刷新已经打开的高校邦播放页，手动开始播放。
5. 点击浏览器工具栏中的扩展图标调整设置。已有匹配页面中的设置会实时更新。

联想浏览器等 Chromium 衍生浏览器是否兼容，取决于其内核版本、扩展管理能力及企业策略；
本扩展要求 Chromium 111+，没有经过该浏览器的实机安装验证。若不兼容，请使用近期版本 Edge 或 Chrome。

## 使用边界

请遵守学校和课程规则。本项目只调整本机播放器的播放行为，不伪造学习时长、不调用进度接口、
不自动答题、不跳过章节或身份验证，也不保证后台播放会被平台计入学时。
不能用它代替实际学习，平台自身的服务端规则仍然有效。

## 暂停与兼容性

- 不会自动开始播放，也不会把所有暂停的视频强制重新播放。
- 前台暂停始终交由播放器处理；近期真实鼠标点击或播放快捷键也允许暂停。
- 不会修改 `document.hidden`、`document.visibilityState` 或 `document.hasFocus()`。
- 后台播放保护只对未结束、无媒体错误且正在播放的 HTML5 视频生效。
- 网页脚本在后台主动暂停可能被阻止，包括某些正常的后台暂停行为；遇到课程提示、弹窗、
  播放故障或其他冲突，请先关闭“后台播放”或扩展总开关。
- 关闭倍速锁定会释放后续速度修改，但不会主动恢复先前倍速；可在播放器中自行调整。
- 扩展不覆盖第三方域名 iframe、封闭 Shadow DOM、非 HTML5 播放器或浏览器自身的节能休眠。
- 站点若提前缓存了原生方法、替换原型或使用其他播放引擎，本扩展可能无法拦截，需要进一步适配。
- 关闭扩展总开关会即时停止保护，但原型包装保留为透传；卸载后刷新页面可完全移除注入代码。

## 权限与隐私

唯一权限为 `storage`，用于 `chrome.storage.local` 存储四项播放偏好。
注入范围为 `https://*.gaoxiaobang.com/*`，不包含其他网站，不请求 `cookies`、`tabs`、
`webRequest`、下载或任意网站权限。源代码和安装包不包含具体课程地址或私人学习资料。
所有代码均随扩展打包，不加载任何 CDN。

## 开发

Node.js 22+；无第三方运行时依赖，不需要 `npm install`。

```sh
npm run check
npm test
npm run package
```

`npm run icons` 可重新生成项目内的 PNG 图标。`npm run package` 会把安装所需文件打包到
`dist/gaoxiaobang-playback-helper-v1.0.0.zip`，不包含测试、Git 元数据或开发脚本。

目录结构：`src/page.js` 在网页主世界处理媒体方法与事件；`src/bridge.js` 在隔离世界读取设置；
`popup/` 提供本地设置面板；`tests/` 提供自动化回归测试；`.github/workflows/ci.yml` 执行检查并打包。

## 验证状态

自动化测试覆盖后台暂停、前台及手动暂停、视频结束、媒体错误、倍速锁定、动态视频、配置校验、
存储竞争条件与最小权限。具体结果见 CI 或本地 `npm test`。

初版在本机通过 15 项 Node.js 回归测试，以及 Playwright 驱动的无头 Edge 冒烟测试：
设置保存、禁用联动、340px/280px 弹窗布局，以及真实 HTML5 媒体元素的后台暂停保护、
1.5 倍速锁定和禁用后暂停。后者使用模拟隐藏状态与本地合成媒体，不等同于实站切窗验收。

实际课程播放页需要登录。未获取账号或绕过登录，尚未在登录后的高校邦真实播放器完成验收。
安装后请先验证：播放后切换窗口、切回后检查倍速、手动暂停、禁用开关及切换下一节。
不要把自动化模拟测试理解为该平台所有播放器版本均兼容的承诺。
